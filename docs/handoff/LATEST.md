## 教訓(今回の運用上の学び)

- **「直した」の範囲を原因で言い切らない**: #326 は「画面高が低い」を原因としたが、Muse の「1080px でも起きた」は別の原因(テキストエリアの無制限な伸長)だった。報告の条件(高さ・状態)と修正の想定条件が食い違ったら、実機で再現して原因を確定する
- **`gh pr merge` は単独で実行する**: `2>&1 | tail` を付けると pr-merge-gate に拒否される(前回の教訓の再確認)
- **ローカル確認は FE のみで足りる場合がある**: `npm run dev`(Express)は Firebase Admin の環境変数が無く起動しない。レイアウト確認は `npx vite --port 3100` で十分(確認後に停止)
