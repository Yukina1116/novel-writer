## 教訓(今回の運用上の学び)

- **「PR → dev 客観検証 → prod」の流れを毎回踏む**: オーナーから確認を受け、流れ自体は守れていた。prod は SHA 一致のみで画面は開かない
- **複合コマンドで `gh pr merge` を実行すると pr-merge-gate に拒否される**: 単独の `gh pr merge N --squash --delete-branch` で実行する。自由記述の返答は承認として扱われないため、AskUserQuestion の選択肢で承認を取る
- **フル実行でフレークが出たときは failures=0 を確認してからコミットする**: #326 では 1 件失敗のままコミットしてしまった(報告済み)
- **一過性のトーストは後からサンプリングすると見逃す**: MutationObserver で出現を捕捉する
