# プライバシーポリシー

- 適用範囲: 「小説らいたー（α版）」（以下「本サービス」）

---

## 1. 取得する情報

### 1.1 アカウント情報（ノートプラン以上）

Google アカウントでログインした場合、以下を取得します:

- メールアドレス
- 表示名（Google プロフィールに準拠）
- ユーザー ID（アカウントを識別するための番号）
- メール認証状態

### 1.2 利用履歴（ノートプラン以上）

AI 機能を利用した場合、以下を本サービスのサーバーに記録します:

- 月別の AI 利用コスト累計
- 利用した機能の種別（小説生成、キャラクター作成・更新等）
- リクエスト ID（同じ操作の重複処理を防ぐため、72 時間程度保持）

### 1.3 創作物データ（クラウドに送信しません）

**重要**: 小説本文・設定・プロット・タイムライン等の創作物データは、ユーザーのブラウザ内にのみ保管されます。本サービスのサーバーには送信・保管されません。

例外として、以下の場合に限り創作物データの一部が外部に送信されます:

- AI 機能を利用した際、必要なテキスト（プロンプト、選択範囲、関連設定）が Google Cloud の生成 AI サービス（Gemini Enterprise Agent Platform）に送信されます（§2 参照）
- ユーザー自身が「全データバックアップ」機能で Export を実行した場合、JSON ファイルがユーザーのローカルディスクにダウンロードされます（事業主体には送信されません）

### 1.4 cookie / localStorage の利用

本サービスは以下の用途で cookie / localStorage を利用します:

- ログインセッションの管理（cookie）
- UI 設定（テーマ、パネルサイズ等）の保存（localStorage）
- 創作物データの保管（ブラウザ内のデータ保存領域）

トラッキング用途の cookie は使用しません。<!-- TODO: 第三者解析ツール導入時に追記 -->

## 2. AI 機能利用時のデータ送信

ユーザーが AI 機能を利用した場合、以下のデータが Google Cloud の生成 AI サービス（Gemini Enterprise Agent Platform）に送信されます:

- ユーザーが入力したプロンプト
- 関連する設定情報（キャラクター設定、世界観設定、プロット等から AI が必要と判断した範囲）
- 選択範囲のテキスト

送信されたデータの取り扱いは、Google Cloud の利用規約および当該 AI サービスのプライバシーポリシーに準拠します。本サービスは送信されたデータをモデル学習等の目的で再利用しません（Google Cloud のデフォルト設定に基づく）。

## 3. 情報の利用目的

取得した情報は以下の目的でのみ利用します:

1. 本サービスの提供（認証、AI 機能の提供、利用上限の管理）
2. 不正利用の検知・防止
3. お問い合わせへの対応
4. 法令に基づく対応

第三者への提供、広告利用、マーケティング目的での利用は行いません。<!-- TODO: 第三者提供方針を確定 -->

## 4. データの保管・委託先

### 4.1 委託先

本サービスは以下の外部サービスを利用しており、ユーザーのアカウント情報・利用履歴の一部を委託先のサーバーに保管します:

| 委託先 | 保管されるデータ | 所在地 |
|---|---|---|
| Google Cloud (Firebase Auth) | アカウント情報 | グローバル（Google が指定するリージョン） |
| Google Cloud (Firestore) | アカウント情報、利用履歴 | asia-northeast1（東京） |
| Google Cloud (Cloud Run) | リクエストログ（短期） | asia-northeast1（東京） |
| Google Cloud (Gemini Enterprise Agent Platform) | AI に送信されたテキスト | asia-northeast1（東京）<!-- TODO: モデル可用リージョン要確認 --> |

### 4.2 保管期間

- アカウント情報: 退会まで保管
- 利用履歴: 月単位で 12 ヶ月保管後に削除予定 <!-- TODO: 確定方針 -->
- リクエスト ID: 72 時間程度（冪等性確保のため）
- Cloud Run / Cloud Logging のリクエストログ: 30 日（GCP デフォルト） <!-- TODO: 保持期間を意図的に設定 -->

## 5. ユーザーの権利

ユーザーは以下の権利を行使できます:

### 5.1 データの確認

「全データバックアップ」機能で、ブラウザ内に保管されている全創作物データを JSON で Export できます。

### 5.2 データの削除

#### 5.2.1 創作物データの削除

ブラウザの「サイトデータ削除」（IndexedDB クリア）で即時削除できます。

#### 5.2.2 アカウント情報の削除（退会）

退会希望の場合、以下の方法で対応します:

1. ユーザー自身による Google アカウントの本サービスへのアクセス権削除（Google アカウント設定）
2. 事業主体への退会申請（連絡先: X（旧Twitter） [@novelwriter_app](https://x.com/novelwriter_app) の DM）

退会後、アカウント情報・利用履歴は<!-- TODO: 削除タイミング確定（即時 / N 日後） -->削除されます。

## 6. セキュリティ

本サービスは以下のセキュリティ対策を実施しています:

- 通信の TLS 暗号化（HTTPS）
- ログイン認証によるアカウント保護
- ユーザーごとのデータアクセス制御（他ユーザーのデータにはアクセスできない設計）
- AI 利用上限による課金保護
- 入力データのサニタイズ処理（不正なコード実行の防止）

ただし、インターネット経由の通信に絶対的な安全性は保証できません。<!-- TODO: インシデント対応方針を追記 -->
